Defects I Found

            

                Seven defects in the EMERGEX accommodation interface. Not one was reachable
                through normal manual use. Every one was caught by an automated test,
                and every one has since been corrected and verified.
            


            


                

                    

                        

                            DEF-02
                            High
                        

                        
A viewing request with no rooms was accepted

                        

                            Business rule BR-06 says a request must name at least one room. Nothing
                            enforced it. The run produced reference RF-261101-3591 —
                            a real stored request with zero rows in
                            viewing_request_rooms. The provider gets a name and a phone
                            number with no idea what the student wants to see.
                        

                        

                             Functional test, business rules
                             Refuse the submission; error beside that section
                        

                    

                


                

                    

                        

                            DEF-03
                            Medium
                        

                        
Rooms from another campus were accepted

                        

                            Rooms were checked for existence but never for location. The run submitted
                            a request for cape-town naming a room in Bryanston —
                            roughly 1 400 km away — and it was stored. The request routes to a
                            campus that cannot act on it.
                        

                        

                             Functional test, business rules
                             Resolve each room and compare its campus
                        

                    

                


                

                    

                        

                            DEF-01
                            Medium
                        

                        
Long names were silently truncated

                        

                            A 200-character name was accepted and stored as 160 to fit the column.
                            Nobody was told anything had been lost, so the provider calls using a name
                            that is not the student's.
                        

                        

                             Functional test, input validation
                             Length check before the transaction opens
                        

                    

                


                

                    

                        

                            DEF-04
                            Medium
                        

                        
The move-in month was never validated

                        

                            Posting move_in=1999-01 straight to the server stored it
                            unchanged. Unreachable by clicking, because the field is a dropdown
                            — which is exactly why it was found by posting rather than clicking.
                        

                        

                             Security test, server-side validation
                             Validate against the twelve months offered
                        

                    

                


                

                    

                        

                            DEF-05
                            Medium
                        

                        
An unknown campus reached the database

                        

                            Validation passed it through; the foreign key refused it; the student saw
                            "We could not save your request just now" with no indication of which field
                            was wrong. The data was protected. The student was not helped.
                        

                        

                             Security test, server-side validation
                             Validate against the campus table first
                        

                    

                


                

                    

                        

                            DEF-07
                            Medium
                        

                        
The form promised an email nothing sends

                        

                            The guardian field read "They receive the same confirmation and lease
                            summary you do." This release sends no email at all. The same claim sat in
                            the For Parents section of the landing page.
                        

                        

                             UI test, content accuracy
                             Reword to describe what the system does
                        

                    

                


                

                    

                        

                            DEF-06
                            Low
                        

                        
The status column accepted any value

                        

                            status was VARCHAR(20) and took
                            not-a-real-status without complaint. It is meant to hold one
                            of four values. Low severity only because nothing reads it yet.
                        

                        

                             Integration test, schema constraints
                             ENUM('new','contacted','viewed','closed')

About Me

                
Hi, I'm Novithan

                
I'm in my final year of a BSc in IT, focused on test automation. I write test cases from requirements and turn them into executable suites using Python, pytest and Playwright, across UI, functional, logic, integration, end-to-end, regression and security layers. My most recent suite is 152 test functions producing 230 executions against a student accommodation platform. It uncovered seven defects, none of them reachable through ordinary use. All seven were corrected, and a second run proved it: 224 passed, none failed. I have used Playwright and Python Stack for this.

My Learning Journey

            

                Seven test layers, each answering a different question — so a defect that
                escapes one is caught by the next. The layer is recorded as a pytest marker, so
                pytest -m security runs that layer wherever it lives.
            


            

                

                    

                        

                            
                            
UI Testing

                            
Does it render correctly?

                            

                                Badges, responsive layout, accessible structure, checked at
                                seven viewport widths. Driven with Playwright using the Page
                                Object Model, so every selector lives in one file and a markup
                                change is a one-line fix rather than a rewrite.
                            

                            40 tests
                        

                    

                


                

                    

                        

                            
                            
Functional Testing

                            
Does it follow the rules?

                            

                                Search, filtering, the shortlist and form validation. Roughly
                                half of these assert that something is correctly
                                refused — a suite that only proves the happy
                                path proves very little.
                            

                            73 tests
                        

                    

                


                

                    

                        

                            
                            
Integration Testing

                            
Does it reach the database?

                            

                                Assertions run against MySQL rows through PyMySQL, not screen
                                text. A page can say “saved” whether or not anything
                                was written — only the row proves it.
                            

                            37 tests
                        

                    

                

            


            

                

                    

                        

                            
                            
End-to-End Testing

                            
Do the journeys work?

                            

                                The whole path a student takes: filter the search, shortlist two
                                rooms, carry them into the form, submit, then read the stored row
                                back. Individual features can each work while the path between
                                them breaks.
                            

                            5 tests
                        

                    

                


                

                    

                        

                            
                            
Regression Testing

                            
Has anything broken?

                            

                                A smoke pack plus one guard per fixed defect, so a later change
                                cannot silently undo an earlier fix. This layer earned itself
                                during the fixes: enforcing one rule turned thirty tests red
                                within minutes, and all thirty had one cause.
                            

                            8 tests
                        

                    

                


                

                    

                        

                            
                            
Security Testing

                            
Do the controls hold?

                            

                                Injection, CSRF, tampering and error disclosure, mapped to the
                                OWASP Top 10. These post directly with requests
                                rather than clicking: client-side validation is a usability
                                feature, never a security control, because the attacker chooses
                                the client.
                            

                            19 tests
                        

                    

                


                

                    

                        

                            
                            
Logic Testing

                            
Is the arithmetic right?

                            

                                The cost estimator across three payment plans, including the rule
                                that carries the most meaning: the discount applies to rent only,
                                never to the deposit or the admin fee. Proven by reading the
                                deposit under all three plans and requiring them to match.
                            

                            13 tests
