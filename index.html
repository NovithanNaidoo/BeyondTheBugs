Defects I Found

            

                Four defects in the EMERGEX platform. None was visible through normal manual use —
                every one was caught by an automated test.
            


            


                

                    

                        

                            DEF-011
                            Critical
                        

                        
Identity documents publicly readable

                        

                            Uploaded NSFAS documents were written to a folder served directly by Apache,
                            with no authorisation check. I uploaded a document, cleared every cookie,
                            requested the file and got HTTP 200 with the contents.
                        

                        

                             Security test, access control
                             Store outside the web root; stream via an authenticated handler
                        

                    

                


                

                    

                        

                            DEF-010
                            High
                        

                        
No room availability check on booking

                        

                            available_rooms was displayed everywhere but never decremented,
                            and the booking code never read it. A property advertising zero rooms
                            accepted unlimited bookings.
                        

                        

                             Regression test, data integrity
                             Availability check inside the booking transaction
                        

                    

                


                

                    

                        

                            DEF-012
                            Medium
                        

                        
CSRF block reported as a server crash

                        

                            The CSRF guard returned HTTP 419 — a framework convention, not a
                            registered status code. Apache did not recognise it and substituted 500,
                            so every blocked submission looked like a server error.
                        

                        

                             Functional test, CSRF
                             Return 403 Forbidden
                        

                    

                


                

                    

                        

                            DEF-013
                            Low
                        

                        
Hidden field stayed visible

                        

                            The script correctly set the hidden attribute, but a
                            label { display: block } rule in the stylesheet overrode the
                            browser default. The field was marked hidden and still on screen.
                        

                        

                             Regression test, rendering
                             Add an explicit [hidden] rule

My Learning Journey

            

                Six test layers, each answering a different question — so a defect that
                escapes one is caught by the next.
            


            

                

                    

                        

                            
                            
UI Testing

                            
Does it render correctly?

                            

                                Badges, responsive layout, accessible structure. Driven with
                                Playwright using the Page Object Model, so a markup change is
                                a one-line fix rather than a rewrite.
                            

                            25 tests
                        

                    

                


                

                    

                        

                            
                            
Functional Testing

                            
Does it follow the rules?

                            

                                Authentication, validation, filtering and access control.
                                Roughly half of these assert that something is correctly
                                refused — a suite that only proves the happy
                                path proves very little.
                            

                            39 tests
                        

                    

                


                

                    

                        

                            
                            
Integration Testing

                            
Does it reach the database?

                            

                                Assertions run against MySQL rows, not screen text. A page can
                                say “saved” whether or not anything was written —
                                only the row proves it.
                            

                            9 tests
                        

                    

                

            


            

                

                    

                        

                            
                            
End-to-End Testing

                            
Do the journeys work?

                            

                                Complete flows across multiple roles — a student books,
                                a landlord approves, a deposit moves through escrow. Individual
                                features can each work while the path between them breaks.
                            

                            5 tests
                        

                    

                


                

                    

                        

                            
                            
Regression Testing

                            
Has anything broken?

                            

                                A smoke pack plus one guard per fixed defect, so a later change
                                cannot silently undo an earlier fix. The whole suite runs in 46
                                seconds, which is what makes it worth running often.
                            

                            24 tests
                        

                    

                


                

                    

                        

                            
                            
Security Testing

                            
Do the controls hold?

                            

                                Injection, access control, CSRF, session handling and file
                                uploads, mapped to the OWASP Top 10. This layer found the most
                                serious defect in the project.
                            

                            16 tests
