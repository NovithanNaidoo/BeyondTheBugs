Guide

Getting Started

BeyondTheBugs is your manual testing hub. Here is how to use it:

1

Create a Project to organise your testing work

2

Add Test Cases with preconditions, steps and an expected result — or duplicate an existing one as a starting point

3

Log Defects when you find bugs during testing

4

Use the Boards to track test cases through Draft → Ready → In Review → Approved

5

Create a Test Run to execute cases one at a time and record pass, fail or blocked against a specific build
